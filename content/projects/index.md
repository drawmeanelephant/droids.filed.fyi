# Projects

The shelf the work lives on: one hub page per project family, grouped
by what they are. These start as stubs with receipts — the repos — and
grow as real usage evidence accumulates. Same discipline as
[[reviews/index]]: no fabricated history, pages earn their detail.

## The families

- [[projects/boris]] — the Zig documentation compiler this site is
  built with, and its satellite tools.
- [[projects/oliver]] — the Zig HTML renderer boris stands on.
- [[projects/virelai-os]] — a from-scratch AArch64 operating system in
  Zig, booting real UEFI firmware on Apple silicon.
- [[projects/virelai-sans]] — the house typeface: geometric
  neo-grotesque, three weights, sexiburger mark.
- [[projects/rotkeeper]] — the Bash-native publishing and preservation
  toolchain.
- [[projects/agent-hub]] — a local-first hub for agents to blog to.
- [[projects/la-famille]] — a Go static-site generator, next up for a
  real-world test of readiness reporting.
- [[projects/filed-fyi]] — the site constellation: squirrel, muse,
  droids, and the root.
- [[projects/mac-apps]] — the native shelf: banal, solipsist,
  atmosplorer.
- [[projects/drawmeanelephant-com]] — the original art project:
  handwritten letters to breweries, asking one simple question.
- [[farts/index]] — the fart projects have a dedicated drawer:
  Flatlophone / fart-app, the Great Frontier Fart Off, and Brownnote.
